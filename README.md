# Anushka Agarwal - Personal Portfolio Website

A modern, attractive, professional, and responsive personal portfolio website for **Anushka Agarwal**, a first-year **B.Tech Computer Science & Engineering (CSE Core)** student at **JECRC University, Jaipur, Rajasthan, India**.

Designed with clean typography, elegant micro-interactions, responsive mobile navigation, theme switching (Light/Dark), and genuine first-year student developer accomplishments—without any inflated or fictional claims.

---

## 🌟 Highlights & Features

- **Accurate & Authentic Persona**: Accurately showcases a 1st-year student exploring C, Python, Web Development, and AI.
- **Modern UI/UX Design**: Uses a clean, modern aesthetic with *Plus Jakarta Sans* and *Inter* typography, soft card shadows, smooth transitions, and a dark/light mode toggle.
- **100% Responsive**: Tailored for seamless display across smartphones, tablets, laptops, and ultra-wide desktops.
- **Pure Vanilla Stack**: Built with semantic HTML5, modern CSS3 (Custom Properties / Flexbox / Grid), and lightweight vanilla JavaScript. Zero heavy or unnecessary dependencies.
- **SEO & Social Preview Ready**: Meta tags, Open Graph card preview (`assets/images/og-preview.svg`), and favicon included.
- **Interactive Micro-features**:
  - One-click **Copy Email** button with instant visual feedback.
  - Interactive **CampusBuddy AI** & **Mess Meal Planner** UI mockups.
  - Interactive contact form with client-side feedback.
  - Smooth scroll spy that dynamically highlights navigation items.
  - Floating back-to-top button.

## 🚀 Quick Start / Local Preview

1. **Directly in Browser**: Double-click `index.html` to open it in any modern browser (Chrome, Edge, Firefox, Safari).
2. **With VS Code Live Server**:
   - Open the folder in VS Code.

3. **With Python (Terminal)**:
   ```bash

   ```
   Then open `http://localhost:3000` in your browser.

## 🌐 Deployment Instructions

### 1. Deploy to GitHub Pages (Free & Easy)
1. Initialize a git repository and push to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio release"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
2. Go to your repository on GitHub.
3. Click **Settings** > **Pages** (under Code and automation).
4. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
5. Your portfolio will be live at `https://<your-username>.github.io/<repo-name>/`.

### 2. Deploy to Vercel (Fastest with Custom Domain Support)
1. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New..."** > **"Project"**.
3. Import your portfolio GitHub repository.
4. Keep the default settings (Framework preset: `Other`, Root directory: `./`).
5. Click **Deploy**. Vercel will provide an instant live URL (`your-portfolio.vercel.app`).
